# MUSHIVERSE V22 ガチャカード制作の再開地点

- 登録構成は初期100、復元100、新規200。初期100種の表示名と、実在種に見えやすい復元9種の表示名を架空名に変更した。初期カードのIDは `mv-classic-001` から `mv-classic-100`。旧名の所持データは読み込み時に対応表で解決する。復元・新規の既存IDは維持。
- 初期100種の旧名称と400種の現行名をNFKC正規化して完全一致を照合。名称確認の資料は九州大学「日本産昆虫学名和名辞書」と日本昆虫学会「日本昆虫目録」。両資料の収録データとの全件照合は未完了。
- 復元100枚と新規200枚の既存WebPはすべてデコードし、SHA-256と画素の完全一致を確認した。重複の一致は0。全300枚の縮小一覧を目視した。復元100枚は480×720の縦長。新規200枚は正方形で、背景・被写体の寄り方が近い系列がある。特に紫晶、紅葉、夕暮れの水辺、霧の森、苔の系列をカード単位で見直す。
- 現在の新作は42枚（`mv-classic-001`〜`mv-classic-042`）。初期カードのうち残り58種は個別SVG。最初の再開IDは `mv-classic-043`。復元・新規と合わせてWebPは342枚。
- `js/gacha-classic-cards.js` の `photographs` が制作・収録済み初期カードの一覧。ないIDは旧来の個別SVGを継続表示する。次の画像は `assets/cards/classic/<id>.webp` に縦長480×720、文字やUIなしで配置し、比較検査後に一覧へ追加する。
- `npm run test:release` は全400種の抽選到達性、SSR 0.1%、ID、名前、旧所持データ、アートの解決とオフライン収録を検証する。`npm run ios:check` はローカルのiOS用素材を検証する。署名後はiPhoneのオフライン状態で単発、10連、所持、図鑑、詳細、新規獲得を確認する。
- 残作業は未収録の初期カード、新規200枚の縦長構図・類似絵の選別と差し替え、目録との広範な照合、署名済みの次回TestFlight用ビルドでの実機確認。次回は `photographs` にない最小番号から進める。審査中のビルドを差し替える操作はこの変更に含めない。
